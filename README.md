# Русская локализация REC 0.6.0.0

Материалы фанатского перевода Asyncoder для игры REC автора moondev.
Текущая версия игры: 0.6.0.0 (Godot 4.7.2 .NET). Перевод 0.5.5.2 перенесён целиком,
новые реплики, предметы, враги и подписи 0.6 переведены.

translation/ — таблицы, ключи строк, тексты, таймлайны и исправления подписей.
translation/v0600/ — новые строки 0.6: реплики, ресурсы, ключи таблиц, строки C#.
tools/patcher/ — исходники патчера .NET 8 с зависимостью dnlib.
tools/patcher/strtool/ — замена строк и вставка перевода в REC.dll для 0.6.
tools/scripts/v0600/ — перенос перевода на 0.6 и сборка пакета.
tools/scripts/ — генератор таблиц и вспомогательные скрипты прошлых версий.
fonts/ — исходные файлы шрифтов с кириллицей.
docs/ — описание перевода и порядок сборки.

Порядок сборки для 0.6.0.0 описан в docs/BUILD.txt.
Ресурсы и исполняемые файлы игры нужно предоставить отдельно.
Ключи шифрования в проект не включены.
Скрипты legacy сохраняют исторические пути и требуют проверки перед запуском.
