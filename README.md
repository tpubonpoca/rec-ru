# Русская локализация REC 0.5.5.2

Материалы фанатского перевода Asyncoder для игры REC автора moondev.

translation/ — таблицы, ключи строк, тексты, таймлайны и исправления подписей.
tools/patcher/ — исходники патчера .NET 8 с зависимостью dnlib.
tools/scripts/ — генератор таблиц и вспомогательные скрипты.
fonts/ — исходные файлы шрифтов с кириллицей.
docs/ — описание перевода и ограничения восстановления сборки.

Для сборки патчера выполните dotnet build tools/patcher/patcher.csproj.
Для генерации таблиц используйте Godot 4.4.1 и проект tools/scripts/table-project;
инструкция находится в docs/BUILD.txt. Для скриптов шрифтов требуется fontTools.
Ресурсы и исполняемые файлы игры нужно предоставить отдельно.
Ключи шифрования в проект не включены.
Полная сборка игрового пакета требует внешних ресурсов и отдельной упаковки.
Скрипты legacy сохраняют исторические пути и требуют проверки перед запуском.
